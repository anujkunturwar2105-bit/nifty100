# Streamlit Financial Intelligence Dashboard

## How to Launch
From project root:
```bash
make dashboard
```
Or directly:
```bash
streamlit run src/dashboard/app.py --server.port 8501
```

## Features
- 8 Interactive Analytics Screens
- Real-time financial ratio filtering
- Dynamic chart visualizations (Plotly & Radar charts)
- Report download center for tearsheets and PDFs
